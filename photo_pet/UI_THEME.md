# 魔法植物手账视觉主题

本次仅更改展示层，保留八页顺序、页面构建方法、信号连接、按钮文案与操作、API、数据格式及角色行为。没有新增依赖。

- `niangao/theme.py`：`TOKENS` 集中管理用户色板与纸张衍生色；Qt QSS 不支持 CSS 自定义属性，使用 `Template` 编译为实际颜色。统一字体层级、导航、按钮、卡片、输入框、焦点及菜单样式。
- `niangao/journal.py`：八章独立纸色、主辅色、植物纹样、纸纤维、边线和标题构图。尖拱、撕边、纸胶带、水彩渐晕、淡纸影与小型植物印章全部即时绘制，没有整屏贴图或拦截事件的覆盖层。绘制仅在纸面/标题边缘；聊天页关闭纤维与植物，不展示标题猫咪或装饰贴纸。
- `niangao/life/window.py`：只接入新纸面、标题、侧栏与复用角色姿态；保留公共组件与现有业务处理函数。标题肖像是可替换的 `chapterPortrait`，与桌宠共用已有年糕姿态，移除原先标题与侧栏中的卡通猫替代图。
- `niangao/life/calendar_widget.py`：仅将日历绘制颜色接入主题变量，不改日期范围、农历换算、选择或翻月行为。

八页：总览/尖拱花窗，照料/蓝绿草本，小铺/橄榄花叶，背包/蕨类标本，专注/浅蓝海岸水纹，聊天/极简信纸，日记/植物学稿纸，设置/种子档案。

## 素材边界

引用的 ChatGPT 会话当前没有可调用的读取工具，因此未导入或声称复刻其中的重绘成果。本版复用已有基于年糕照片的姿态资源，保留蓝眼、深色面罩、白纹与鼻侧斑点等既有特征；这些资源包含此前 AI 补全，并非新完成的真实毛发或手工水墨重绘。完整自然水墨排线、多角度重绘素材尚待提供与核对；替换肖像不需要修改业务逻辑。原有商品图像及桌宠动作资产没有重做。
