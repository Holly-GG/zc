# Reference redraw assets · 2026-10-29

Generated with the image generation tool using the user's latest floral eight-page UI mockup and two Niangao ink/watercolour pose sheets as visual references. These are AI illustrations, not photographs or a claim of exact anatomical reconstruction. The nose-side brown patch, asymmetrical white blaze, blue eyes, chocolate mask, white chest/paws and long fluffy tail were explicitly requested and visually reviewed.

- hero.webp: Niangao, lilies, forget-me-nots and Gothic garden window; decorative artwork only.
- border.webp: transparent botanical perimeter ornament; center is transparent. Rendered as nine slices to preserve corner scale on long pages. No controls/text baked in.
- poses.webp: four-cell transparent illustration atlas: resting, portrait, stretching, sleeping. Read-only UI source rectangles choose poses; original desktop pet animations are unchanged.
- paper.webp: low-contrast unprinted cotton watercolour paper texture, omitted from chat background.

Original generated PNGs remain in /workspace/generated_images; shipped WebP copies only change encoding, retaining dimensions and alpha. No existing photo/action resources were deleted. All text, fields, buttons, lists, progress indicators and navigation are real Qt widgets above the ornament layer.
