# User-provided full-page artwork

Eight PNG originals from the user's 新建文件夹.zip, explicitly supplied for full-page wallpaper with layered real click/input regions. Runtime WebP files are lossless; tests compare every decoded RGBA pixel against docs/design-system/reference-originals.zip. No image generation, repainting, crop, face mirroring or lossy conversion was used. provenance.json records ZIP filenames and original/runtime SHA256 values.

The entire illustration layer including navigation and static button text is original artwork. Current dates, state, inventory, profile, diary and chat are real widgets drawn above it. Static example values are not used as game data. Album sample art is marked illustration cover, not a user photo. Unsupported items are disabled; absent destructive data operations are replaced by actual settings/history entrances.
