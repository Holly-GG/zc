# 模型接口兼容与连接测试

支持文本聊天与 AI 日记，四类非流式协议：

| 协议 | 使用方式 |
|---|---|
| OpenAI Chat Completions | DeepSeek、通义百炼、Kimi、智谱、硅基流动、火山方舟、文心千帆、OpenRouter、Groq、Mistral，以及自定义兼容服务 |
| OpenAI Responses | 支持该协议的 OpenAI 模型或兼容网关 |
| Anthropic Messages | Claude 原生服务或提供此协议的服务 |
| Gemini GenerateContent | Google Gemini 原生服务 |

设置中提供可编辑预设。模型 ID 以账户控制台为准；某些服务要求部署 endpoint ID。预设不代表每个地区、账户或型号均可用，也不代表已用真实密钥逐一测试。旧版只会拼接一种 OpenAI 路径，本版支持基础地址及完整接口路径，避免重复追加。

OpenAI 新思考模型使用 max_completion_tokens；DeepSeek reasoner 等思考模型增加输出预算和超时。仅思考而没有正文会提示失败，不把内部思考内容显示为年糕回复。DashScope Qwen3 非流式请求显式关闭 enable_thinking。其他服务若有特殊参数，可先使用标准聊天模型；本版不是所有私有签名、OAuth、工具调用、流式、图像或音频 API 的通用 SDK。

## 实际测试

1. 打开“性格与设置”，选择平台、协议和控制台模型 ID。
2. 在本机密码输入框填写 API Key。远程地址必须为 HTTPS，密钥使用 Windows 当前用户 DPAPI 加密，不写入普通 JSON、日记或聊天历史。
3. 点击“保存并测试连接”。这个明确操作会发送一条测试消息和最新年糕档案，即使自动联网聊天开关没有开启，也会执行这一次测试。服务商可能收取少量调用费用；思考模型的消耗可能高于普通模型。
4. 只有收到可解析的非空正文才显示连接成功。失败会区分 400 参数、401 密钥、402 余额、403 权限/地区、404 地址/模型、429 限流/额度、超时及格式错误。
5. 不要在聊天、截图、日志中分享完整 Key；排查时只提供平台、模型、地址和已脱敏的错误。

切换服务域名需要重新填写对应密钥，防止把旧 Key 发送到另一个平台。选择预设本身不会删除旧密钥；保存后才更新。当前版本不自动探测远程服务，不重试计费请求，不把密钥放进 URL；HTTP 重定向仍被阻止。

## 自测边界

自动测试使用本机 HTTP 模拟服务，逐一验证四类真实请求格式、鉴权头、回复结构、档案更新、异常处理和密钥不泄漏。它们证明客户端协议处理符合测试用例，不证明任何第三方账户当前有权限、余额、地区可达性或指定模型访问权。

本开发环境出站域名受策略限制，未使用用户真实密钥连接服务商。实际连通性应使用本机“保存并测试连接”验证；不可将协议自测通过称为真实服务连接成功。
