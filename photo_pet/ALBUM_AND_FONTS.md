# 手账界面、字体与本地相册

原有八页及其索引不变，“宠物相册”追加为第九页。桌宠动作、物品交互、API 配置、聊天历史和 token 预算继续保留。

## 相册

打开“宠物相册”→“导入照片”→选择本机图片，可一次选多张。图片不会发送到 API，也不会删除或移动原文件。

默认优先读取 JPEG EXIF 拍摄日期；未提供时和其他格式采用文件修改日期。可勾选“指定归档日期”，或在详情修改标题、分类、日期和备注。日期修改会把相册副本移到对应日期目录。提供月份/分类/文字筛选、日期排序、分页、原图预览、导出原图和移除相册副本。移除操作要求确认，原始源文件始终不删除。

数据位于 `%APPDATA%/NiangaoPhotoPet/album/`：`album.sqlite3` 为索引，`YYYY-MM-DD/` 保存原始字节副本，`thumbnails/` 保存预览。备份时退出程序并复制整个 album 目录，不能只复制缩略图或数据库。图片副本保留原始 EXIF，包括可能存在的位置等信息；导出与分享前请自行确认照片内容与元数据。

支持 JPG、PNG、WebP、BMP、GIF（首帧预览），不自带 HEIC 解码器。单文件限制64MB、4000万像素，每批最多256张。缩略图会自动按 EXIF 方向显示，原图字节不改变。重复仅按文件 SHA-256 判定，不是相似画面识别。导入可取消；退出程序时会停止尚未完成的导入，已归档的照片保留。部分失败时保留已成功文件并显示原因。相册从空状态开始，演示图片不打进用户相册。

## 字体

仓库根目录 `fonts/` 与 `Niangao-Fonts.zip` 是用户要求的字体包，包含三份 TTF、roles.json、来源/校验清单和 OFL 许可证。中文正文使用 Noto Sans SC 子集，标题使用 Noto Serif SC 子集，英文副标题使用 Allura 子集；内部名称统一为 Niangao 字体家族。字体只影响显示，不改变 API 模型或聊天内容。

独立 EXE 已包含字体，无需安装。ZIP 同时附带 `fonts/`，放在 EXE 旁边的包会优先读取，便于后续修改；单独下载 EXE 时也可另外放入该文件夹。配置说明见根目录 fonts/README.md。更改后重启程序；删除旁置包恢复内置字体。不要移走用户数据目录。

## 验证与素材

已有测试加上相册专项测试，验证复制/日期/方向/重复/错误/重启/导出/移除及字体配置。发布前 Windows 工作流另验收打包后的相册异步导入和三种内置字体，以及原有 Win32 鼠标穿透、拖拽和工作台键盘输入。

布局适配740×540、860×650，宽屏1260×820增加分栏。装饰与控件分离，照片和角色不拉伸；角色候选插画保留待确认标记，没有假定用户确认其精确还原。新背景只绘制无动物花窗/植物，不代替真实年糕。原商品图和照片动作未逐张重绘。
