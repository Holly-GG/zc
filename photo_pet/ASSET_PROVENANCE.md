# 年糕照片资产来源

用户在需求中提供了真实年糕的坐姿全身照、面部近照，以及一张绿青色系 UI 色板。真实参考以用户照片为准。聊天中的原始图片未作为可读本地文件交付，因此没有伪造原图文件或声称做了逐像素无损抠图。

当前资产由图像编辑工具直接参考聊天猫咪照片，生成去背景/补全照片；再以该透明全身资产生成左右各四帧爬行和蜷睡。它们是 **AI 编辑和补全结果**，不是最终扫描模型，也不是经过用户确认的完全精确还原。原始生成 PNG 保留不动，程序按 Alpha 边界裁剪显示/按 atlas 分帧，不使用代码伪画照片面部。

- `niangao-idle.png`：1127×1395，RGBA 透明全身坐姿。保留可见鼻侧棕点、粉鼻、蓝眼、深面罩/耳、非对称白纹、白胸/爪。遮挡爪子及尾部由模型推测。
- `niangao-walk.png`：2172×724，RGBA，向右四个等宽连续姿态，程序按 543 像素宽显示；不镜像，以免反转鼻点和额纹。
- `niangao-walk-left.png`：2172×724，RGBA，向左四帧重新生成的步态，面部不镜像。
- `niangao-sleep.png`：1536×1024，RGBA，闭眼蜷睡，属于未在原照中出现的补全姿态。

四肢步态和毛发外观不是物理模拟；少量毛边可能存在半透明颜色残留。用户若需要严格像素级原图抠图与更精准的活动姿态，需要原始照片文件和更多站立/背面/双侧/睡眠参考，并对生成帧逐张验收。真实照片优先于当前编辑结果。


## 生活馆升级素材

assets/actions/ 内 groom、stretch、feed、pet、play_bow、yawn 六组四帧 PNG，由图像编辑工具参考年糕生成。补全肢体是推测，不是从遮挡原图恢复；保持鼻旁棕点与不对称白纹、不镜像。统一裁剪，不交叉淡化；关键帧检查仍非所有缩放下无瑕疵保证。

assets/models/：Blender 4.3.2 程序简化建模与有方向毛带，非照片扫描或最终写实模型。仅整体呼吸。源码 tools/modeling/build_niangao.py。

assets/fonts/NiangaoSans.ttf：Google Fonts Noto Sans SC 的 400 字重子集，内部更名 Niangao UI Sans；OFL 1.1，许可 licenses/NOTO-OFL.txt。tools/subset_font.py 使用 fonttools 4.55.8，仅生成字体时需要。


## 表情与动作补充

assets/motion/a.webp 至 h.webp：根据年糕原有全身形象和用户新提供的脸部表情参考，由图像编辑工具生成 8 张透明照片补全图集。32 套动作共 128 个不同关键帧。采用无损 WebP 并校验非透明 RGBA 像素一致，保留原始生成文件，不覆盖旧图片。

图集并非严格等格，tools/component_frames.py 按主要 Alpha 连通轮廓标注，运行时用逐帧区域隔离相邻猫咪；不通过几何翻转换朝向。该工序只分离图集帧，不重绘身体；微小游离胡须可能不保留。资源映射、共享变体和真实程度见 MOTIONS.md。

九种音效由 niangao/interaction/audio.py 在本机用确定性信号合成，无外部录音；不是年糕实录，不声称具有真实录音品质。无录音授权或第三方音频样本依赖。


## 手绘生活馆与桌面用品

assets/ui/ 下四张透明插图由图像工具参考用户提供的线条画风生成：欢迎、饮水照料、购物、日记。角色统一为年糕布偶猫，保留蓝眼、棕色面罩/耳朵、不对称白纹、粉鼻旁查看者右侧棕点；没有沿用参考图里的狗或商标。属于适配画风的插画，不是照片级还原。

assets/items/ 下 44 个 SVG 为原创可编辑的商品实物插图，脚本 tools/create_item_art.py；动物品牌标记统一采用年糕的猫脸特征。普通食盆和基础粮碗有意使用同一碗型，其他商品有独立绘制。鼠型玩具与鱼干是物品形态，不是替代年糕的吉祥物。水位和水流由程序实时绘制，非录制 GIF。原 3D 资产仅留作历史源文件，不嵌入当前 EXE。
