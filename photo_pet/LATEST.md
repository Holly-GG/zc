# 年糕桌面扩展：本次逐条结果

1. **动作比例**：固定舞台、共用落脚线，使用 `assets/motion/scale.json` 逐姿态标注头部像素尺度。不同动作不会再改变窗口宽高；保留趴卧、伸展的自然体态差异。图片存在透视差，校准并非照片测量的三维精度。
2. **工作模式**：右键猫咪或托盘切换。96×96 静态头像参考本次照片，保留不对称白纹、蓝眼和鼻侧棕点，支持拖动；点击打开小对话窗。离线可用本地互动；主动开启 API 后可联网对话，每次仍读取最新性格、习惯、真实年龄。无输入时不自行联网。普通位置/尺寸与头像位置分开保存。
3. **猫爪日历**：2020–2069 年公历与中国农历、闰月和传统节日；中国标准时间 UTC+08:00。旧版无时区历史记录不猜测迁移。实际电脑时钟错误时仍需修正系统时间；HTTP 日期校准沿用用户显式开关。未编造未来法定节假日调休。
4. **桌面实物**：50 件商品有 SVG 实物图。新增隧道、激光笔、软垫窝、小毯子、草地垫和冻干颗粒。支持掉落、窗口顶边及已落地摆件平台、球弹跳、老鼠跑动、羽毛轻摆、模拟激光点。右键可固定/恢复掉落，左键拖放。工作模式让动态玩具安静下来。
   冻干每份八颗，右键一次掉一颗；Shift+右键打开菜单。吃掉才消耗单颗，收回/重启保持剩余，不会清理补满或无限掉落。心情、精力、饱食度影响食物/玩具接受概率；拒绝不消耗，偶尔会把玩具拨开。最多 32 件，一键清理只收回本程序用品。
   猫树提供抓握、移动和蹲守；吊床看风景/休息；地毯打滚/踩奶；草地观察/扑抓。隧道使用前景遮挡与路径穿行。均为二维演出；没有恢复已删除的 3D 空间，也不声称完成三维碰撞、真实排泄、真实日照检测或长帧骨骼运动。
5. **独立专注窗**：计时、暂停/继续、待办勾选和添加，可拖动并保存位置。遇见用户任务中的喝水、学习、工作、休息等关键词时给出相关短句；靠近触发同一任务一次，并有 90 秒冷却。工作模式关闭靠近主动提醒。
6. **本地语言**：40 场景 × 25 条，共 1000 条独立文本，由场景内短语组合编写，不是联网模型。避免最近八条重复，包含照料、探索、拒绝、玩具、家具、专注、安慰及小调皮。联网聊天独立使用档案前提。

首次升级会赠送一套扩展用品；已有背包、性格、任务与日记继续保留。资源来自参考照片的 AI 编辑补全，不能保证每个比例和关键帧都没有细微视觉偏差。真实照片仍优先。

## 验证

源码测试覆盖逐日历法往返（18,263 天）、春节/闰月、跨时区日期，30/60/144 FPS 平台落地，心情概率、1000 台词唯一性、固定舞台、静态工作模式、本地对话、待办计时与冻干分颗防复制。X11 真实鼠标完成背包拖出、物品透明区穿透及一键清理。Windows 流水线另执行打包 EXE 冒烟和真实 Win32 鼠标输入，最终结果以随包日志及本次构建为准。
