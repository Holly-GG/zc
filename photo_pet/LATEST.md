# 年糕手绘生活馆：逐条修改结果

| 用户要求 | 本版结果 |
|---|---|
| 删除生活馆 3D 空间 | 删除该页面及 3D 运行模块；当前 EXE 不包含模型、Qt3D 依赖或房间入口。旧版空间保存记录保留在用户 JSON 内，不强行覆盖。 |
| 性格填写空间 | “性格与设置”增加性格、日常习惯、喜欢/不喜欢、说话风格、主人称呼、真实观察；生日仍单独可设。 |
| API Key 接入强制读取档案 | 请求层统一强制获取最新档案、生日计算的真实年龄、性别、品种、偏好、外观和当前心情，放入系统前提。聊天、AI 日记、更换 Key、直调请求层均不能跳过；未提供档案会在联网前报错。留空信息标为未知。 |
| 商城与背包分开 | “年糕小铺”购买，“我的背包”显示拥有及可摆数量，拥有的物品可从图像直接拖出。 |
| 每件物品都有图像 | 44 个可编辑 SVG 商品实物图；粮袋、小鱼干、罐头、猫条、玩具、梳子、猫窝、照料包等。普通食盆与基础粮碗共用同一碗型；未适配服饰/特效仍明确禁售。 |
| 桌面摆放与一键清理 | 从背包/照料图像拖到生活馆外放置，也可按“摆放”；桌面上左键拖动、轻点使用、右键收回。一键清理只收回本程序摆件，不动桌面文件或其他程序。 |
| 喝水体验 | 清水碗和猫耳饮水机有独立实物窗口、水位百分比、涟漪/循环水流；一次有效喝水消耗 20%，空了提示补水，右键加满；沿用 20 秒照料冷却。 |
| 互动窗口变小 | 生活馆由 1100×780 调整为 860×650，最小 740×540（小屏按工作区继续收缩）；气泡由 244×82 调整为 210×74。角色大小仍按用户设置保存。 |
| 无点击时主动互动降频 70% | 20 秒未点击年糕、用品或生活馆后进入安静陪伴；自动动作、气泡、光标/打字反应冷却、边缘提示和打呼的计划间隔乘 3.33，频率为原来的 30%。不是降低渲染帧率；专注钟、照料冷却等功能计时不受影响。 |
| 可爱线条 UI 全部改成年糕 | 奶油纸张网格、墨色线条、柔和薄荷/奶黄/浅粉、不同模块配不同年糕插图。吉祥物保留蓝眼、深棕面罩、三角猫耳、不对称白纹和粉鼻旁棕点，不使用小狗或参考品牌标志。 |

## 操作提示

- 先退出旧版，再双击新版 EXE。Windows 10/11 x64，无需安装 Python、Godot、Blender。
- 在背包按住物品图像，拖到生活馆窗口外再松手；Esc 取消。桌面摆件也可继续左键拖动。
- Windows 生活馆正在使用时临时排在年糕上方，避免角色挡住背包按钮；切换应用或隐藏生活馆后恢复普通窗口层级。
- 轻点实物进行照料或使用；饮水机/水碗右键可补水。空水位不会虚假增加照料数值。
- 点“一键清理桌面摆件”或右键菜单同名选项收回。装饰和玩具仍在背包；已真正使用的消耗品按原规则扣除。
- 新版提供一次基础用品体验包；重启不会重复发放，也不会重置原有金币、日记与任务。
- API 默认关闭。开启后，“聊天文字及年糕档案”与“游戏事件及年糕档案用于 AI 日记”分别选择。Key 仍由 Windows 当前用户 DPAPI 加密，绝不写进普通角色 JSON。
- 保存性格或更换 Key 时清空本次会话发送历史，避免旧设定继续影响后续；屏幕上的历史聊天仅作展示。
- 普通点击不丢失；20 秒后仅降低主动打扰。光标/键盘联动默认关闭，键盘联动只读按键活动布尔值，不记录文字。

## 资产与文件

新模块：life/profile.py 强制档案来源；interaction/autonomy.py 安静陪伴规则；desktop_items.py 物品拖放、状态、保存、回收；life/item_art.py SVG 渲染。商品插图在 assets/items/，模块年糕插画在 assets/ui/，编辑生成脚本为 tools/create_item_art.py。

数据仍保存在 %APPDATA%/NiangaoPhotoPet/。life.json 新增 profile、desktop_items 和一次性体验包标记；settings.json 位置/尺寸配置兼容旧版。桌面摆件不以文件形式写入 Windows 桌面目录。

## 验证与边界

基础/界面/养成/API/新功能共 55 项测试；真实鼠标背包拖出、透明区域传递与清理检查；Windows 流水线另外验收 44 张商品图像、档案、饮水机消耗/补水、原生物品点击/拖动、背包拖出和清理。只有最终构建验收通过才发布。以 ZIP 内日志与对应工作流为准。

“强制读取”指客户端每次请求都发送最新资料，不代表能强制外部模型百分之百遵循。未填写的性格习惯不会冒充已知事实。开启 API 时，档案也会发送给所填服务。

喝水使用已有低头/舔嘴照片姿态及独立水流、水位效果，不是精确的三维嘴部接触或流体仿真。手绘猫脸是风格化适配，真实照片仍是长相依据。多屏、混合 DPI、不同声卡和全部第三方窗口仍需用户设备回归。
