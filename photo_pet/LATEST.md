# 本地长会话与 token 管理

- 完整聊天保存 SQLite 和逐会话 JSON，日期检索、分页原文与导出；新建会话不删除旧记录。
- 实时显示当前 messages 的离线估算与保守预算；服务商返回 usage 后按实际输入/输出/思考用量核销。
- 地址＋协议＋模型分别保存上下文窗口和摘要阈值。临近阈值先摘要，再创建新会话/JSON，携带摘要与近期消息继续回复。旧原文和摘要失败时的消息均保留。
- 每日上限和提醒比例可设置，默认500,000、80%。摘要、聊天、连接测试和AI日记共用账本；并发预留防止多窗口重复放行，额度不足联网前提示。
- 仅允许轻量思考，普通DeepSeek关闭thinking，输出最多2,048，不再自动提高预算；深思专用模型直接提示改用普通模型。

计数边界：实时统计是明确标注的模型通用估算，不是官方精确tokenizer，保守阈值可能提前摘要；本地余量不是API账户余额。完整历史从本版开始记录，旧版未落盘的内容不能补回。详见 [会话与token说明](CHAT_MEMORY.md)。

# 设置选择与工作台输入修复

- 设置中的 API 平台预设、接口协议与音效选择不再随滚轮/方向键切换；点击下拉框，再点击选项修改。滚动设置页面时不会误改接口。
- 进入工作模式会自动打开“年糕 · 桌面工作台”，直接显示输入区和发送按钮。关闭工作台只会隐藏；点击工作模式猫咪或右键菜单“打开桌面对话 / 应用搜索”可重新打开。
- 两个页签：“API 对话”包含独立输入框、消息区、发送/清空按钮，以及“使用已配置 API 对话”开关；“应用搜索”搜索功能、物品、动作和用户待办，点击结果跳到对应页面并定位物品或任务。搜索在本机完成，不是网页搜索。
- 工作台使用应用已保存的 API 配置和密钥，每次继续读取最新年糕档案。开启 API 需要用户明确勾选；未开启会标注本地回应。连接失败明确显示错误并保留待重试文字，不混用本地回应冒充 API 成功。请求中输入/发送暂时锁定，避免回车连发产生重复请求。

新增五项测试覆盖鼠标选择、禁滚轮、工作台自动显示与恢复、搜索跳转，以及本机 HTTP 的真实工作台对话、档案注入、失败重试和重复发送保护。全套 102 项回归通过；Windows 构建另外验收实际键盘输入和回车发送。

# 年糕轻待机与桌面照料升级

1. **工作模式换形象**：移除运行包中的头像裁图，改用完整年糕照片姿态。随机播放歪头、眨眼、理毛、舔爪、轻甩尾、哈欠等轻待机，间隔安静站/坐，不自行走动、追光标或主动聊天。保留鼻侧棕点和统一比例。点击仍打开小对话窗；普通模式与工作模式位置分别保存。
2. **食物掉落和进食**：冻干每份八颗，粮袋每份十二粒，右键一次掉一颗；Shift+右键打开菜单。颗粒从袋口落下，有轻微反弹和横向散落，然后停稳。剩余数量、颗粒库存和部分包装会保存，一键清理不补满、不复制食物。
   轻点落稳的食物后，按心情/饱食度决定是否接受；接受后走近、闻一闻、进食、舔嘴。完成进食才扣库存；提前拖走、切工作模式、清理或打断不会扣食物。吃完后打断不会把已吃掉的食物返还。食物不会一点击就消失。
   基础粮碗显示三份余量，吃完一份减一，空碗有空碗图像；右键可补满虚拟基础粮。水碗与饮水机继续保留水位、补水效果。
3. **猫砂互动**：轻点猫砂盆后走近、闻砂、刨砂、安静如厕、盖砂和整理爪爪。完成后增加一团待清理猫砂，最多三团；满了会提示铲砂。右键“铲砂清理”或照料页“清猫砂”清理，重复清理不刷奖励。状态随桌面摆件保存；收回物品为收纳整理。属于二维姿态演出，不是生理仿真或新增完整如厕骨骼动画。
4. **UI 升级**：奶油白与鼠尾草绿、年糕蓝眼/面罩/不对称白纹/鼻侧棕点线稿标识、侧栏分区、顶部随机待机/专注/整理快捷入口、轻边框商品卡片。商城与背包继续独立；照料页新增粮水余量、猫砂状态和当前互动阶段。联网每次强制读取最新性格、习惯、生日和年龄的规则保留。
