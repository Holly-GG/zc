## 长相、动作与穿模说明

默认桌宠继续使用参考照片的 AI 编辑补全图片。粉鼻旁棕色点位于查看者右侧，保持不镜像；真实照片仍是长相判断依据。原图不可见的肢体由 AI 推测补全，不能宣称逐像素还原。

六组新增动作按四个独立关键帧制作，分别检查可见肢体数量、爪子与身体关系、鼻侧棕点及透明背景。复杂动作未启用。统一每组裁剪范围，防止逐帧缩放抖动；不做会产生重影的肢体交叉淡化。帧数较少，动作可能有细微毛色/比例变化，不能保证每个像素、每种缩放下完全无瑕疵。

3D 是**实验性程序模型，不是最终年糕模型**：四肢、颈部、耳朵、胸毛、蓝眼、粉鼻与独立棕点、不对称白纹、尾巴及带方向的细毛带；形体明显简化。毛带不是照片校准的真实长毛 groom。仅整体轻微呼吸，未启用复杂骨骼或服饰。家具保守占地盒与中央猫区验证不等于完整毛发/肢体连续碰撞证明。

可编辑源文件 assets/models/niangao-model-source.blend，另行交付 Niangao-3D-source.zip。GLB 内嵌 exe，运行无需 Blender。低于 OpenGL 3.3 的设备保留静态预览并显示原因。

## 数据与网络

默认显示生活馆，右键猫咪或托盘的“年糕生活馆”重新打开；关闭生活馆不退出桌宠。右键“退出程序”关闭全部。

用户目录 %APPDATA%/NiangaoPhotoPet/：
- settings.json：兼容旧版位置、尺寸、置顶和巡逻。
- life.json：养成、背包、任务、日记、布局；30 秒及重要操作自动保存。
- api-key.dpapi：仅当前 Windows 用户解密，不写入普通 JSON；非 Windows 开发模式只在内存暂存。
- custom.png：导入单姿态图；crash.log：启动错误。

AI 默认关闭。聊天仅发送主动输入及最多八条本次会话上下文；AI 日记须另行开启，仅发送所选日期最近最多六十条游戏事件。25 秒超时、远程 HTTPS、拒绝重定向、不禁用 TLS 验证。服务商可能收费，程序不内置密钥。离线仍可用本地日记和养成。

## P1 美术验收需求

1. 正面、左右侧、背面、腹部、四爪、尾巴及鼻侧斑点清晰自然光照片和尺寸比例。
2. 真实长毛分区梳理、毛流、密度与 LOD；保留颈部与棕点；蓝眼角膜/虹膜材质。
3. 专业四足骨骼、足底 IK、肩胛与尾巴控制；检查爪子/胸毛/尾巴/耳朵接触。
4. Idle、叫名回应、摸头、前伏、追逗猫棒、纸箱休息、双向走跑、睡眠完整循环。
5. 每件服饰在全部姿态下检查贴合、毛发遮挡、穿插后才开放。
6. Windows 10/11 混合 DPI、显示器热拔、各显卡与受保护应用实机回归。
