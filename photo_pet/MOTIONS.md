# 年糕表情、动作与声音升级

沿用现有照片桌宠。新增 8 张透明姿态图集、32 套独立动作资源、128 个不同关键帧；合计 47 个动作 ID（含 6 个明示共享资源的变体）。每套新动作 4 帧，属于照片补全关键帧动画，不是录像、全骨骼动画或 3D 毛发仿真。实验 3D 家园模型此次未新增完整骨骼动作。

## 使用方式

| 操作 | 行为 |
|---|---|
| 轻点角色 | 先眯眼回应，再随机踩奶、蹭手、翻肚或继续呼噜 |
| 原地按住左键约 0.85 秒 | 轻啃指尖回应；松开不会再次触发摸头 |
| 左键拖动 | 立即中断旧动作，随机悬挂、蹬腿挣扎或缩成球；位置可拖动并保存 |
| Shift + 左键小幅滑动 | 抚摸，不移动窗口 |
| 双击角色 / 右键“戳一下” | 随机受惊小跳、生气甩头、扭头不理或炸毛，再甩耳朵 |
| 右键“喂吃的” | 干饭 → 收尾舔嘴 → 开心蹭腿（画面不含真人腿） |
| 右键“逗年糕玩” | 摇屁股蓄力 → 扑抓 → 躲闪 → 拍爪 |
| 生活馆“照料与动作” | 分类图鉴、关键帧预览、手动播放、七类以上情绪体验 |
| 设置“允许追逐光标” | 附近蹭鼠标或潜行蓄力后扑抓，随机失落 / 炫耀 |
| 设置“允许打字联动” | 检测按键活动后，随机拍键盘、探头或点头；不读取屏幕 |

光标追逐默认关闭，只读光标位置。不会隐藏、抓取、锁定、移动系统光标或点击别的程序。“叼住光标”是嘴边的模拟标记，不是真正劫持鼠标指针。桌面移动继续使用工作区和窗口外边界限制；新姿态可交互区域继续跟随逐帧 Alpha，而不是用整个矩形挡住下层应用。

## 情绪与年龄

自主动作每 12–25 秒按实际养成心情选择，睡觉/拖拽/按住/菜单期间不打断。低落或委屈偏向低头、害羞、期待；开心偏向踩奶、蹭手、打滚；兴奋偏向抬爪、蓄力和扑抓；平静偏向理毛、舔爪和甩尾。图鉴可临时体验害羞、委屈、生气、犯困、兴奋、无聊和期待，不修改养成数值。独立的抚摸、投喂、戳击、拖拽序列可互相打断，不在放下角色后继续旧的喂食序列。

“优雅踱步”复用左右步态，实际移动速度减半；不是新增第二套走路美术。年龄沿用生日系统，决定奶喵/成猫喵/老猫低唤的日常选用；独立幼猫/老猫外观仍未制作。

## 音效与隐私

九类本地合成示意音效：奶喵叫、成猫喵呜、老猫低唤、呼噜、吧唧、哈气、抓挠、铃铛、打呼。**不是年糕真实录音，也不宣称是拟真的实录猫声。**默认静音，可在设置开启、调节音量、逐类试听或立即停止。Windows 使用系统 winsound 异步播放 PCM WAV，无需下载音频包；音频设备不可用时保留动画并提示。音量按约 10% 档缓存于用户目录 audio-cache，调至零立即停止。

全局打字联动仅限 Windows，默认关闭，使用按键是否按下的布尔活动查询；不安装键盘钩子，不保存键值、文字、窗口标题、剪贴板或聊天内容，不上传活动。关闭后不再执行查询。键盘上的任何普通键都可能触发动画，不是文字语义分析。AI 聊天原有开关与本功能互相独立。

## 美术边界与检查

新增脸部照片用于蓝眼、深棕面罩、侧耳、自然眯眼/期待/低落、不对称白纹及粉鼻旁棕点参考；默认不镜像，避免把鼻点换边。不可见身体姿态仍由 AI 推测补全，不能宣称逐像素复原，也不能据此判断现实猫咪情绪。

生成图集的猫咪并非完美等格摆放，因此按每只猫完整的连通轮廓分离并记录逐帧裁剪/绘制区域；不直接按固定四等分截断耳朵和尾巴。验证 128 帧主要不透明轮廓完整保留，每套帧使用同一画布尺寸；相邻姿态不会混入。细小游离胡须和低 Alpha 毛边仍可能在二值输入区域下被裁掉。没有为掩盖跳变使用叠影淡化；四帧之间仍可能有细微毛色/形体变化。

肉眼逐帧检查可见四肢、耳尾和鼻部，未发现明显多余肢体或躯干穿插；这不等于所有缩放/姿态下绝对无穿模的证明。慢舔动作主要表现肩部与侧腰，爪子另有独立动作；不是全身每根毛都动态梳理。真实长毛物理、跳上第三方窗口、家具攀爬和服饰骨骼碰撞仍未启用。

## 验证与重建

Python 3.12 / PySide6 6.8.3。基础、界面、养成、API、序列、隐私开关、PCM 音频等 50 项测试；另有 47 个动作 ID 打包 smoke、128 帧轮廓检查、Linux X11 真实输入回归和 Windows 原生验收。最终发布结果以相应 GitHub Actions 运行与 ZIP 内日志为准，不能用开发环境模拟代替所有用户显卡/声卡/多屏回归。

资源编码为无损 WebP；检查所有非透明 RGBA 像素与生成 PNG 一致。原始生成文件名与哈希见 assets/motion/provenance.json；矩形与轮廓片段在 atlases.json。编码和分帧脚本 tools/prepare_motion_assets.py、tools/component_frames.py，不在运行时联网生成图像。
