## 素材与真实内容分开

`photo_pet/assets/ui/layers/components/` 包含八个参考主题，每主题12个独立PNG，共96个。逐项来源图集、裁切坐标、尺寸、SHA-256与状态在 `manifest.json`。

| 文件 | 展示责任 |
| --- | --- |
| paper | 不含对象的纸纹底面；原尺寸低透明度平铺，避免长页面把纹理拉糊 |
| frame | 中心透明的外框；只延展边线，不把内部装饰拉满页面 |
| header | 无字页眉纸面；分层边饰、真实标题与副标题 |
| card | 无字内容卡底面 |
| button / button-active | 普通、悬停和选中按钮底面；标签与事件来自QPushButton |
| input | 输入框底面；输入、光标、选择、占位提示均为原控件 |
| navigation | 导航选中底面；九个名称、图标、索引与信号真实保留 |
| corner-top / corner-bottom | 独立植物贴画，装饰不接受输入 |
| character | 按参考重建的角色候选，未替换既有角色、未追认身份确认 |
| objects | 独立物件贴画，放在预留插画列，不作为页面截图 |

这些图层是通过图像工具参照八张原图重建，再机械拆分的组件，**不是原画源PSD，也不宣称每个像素与原图完全一致**。原始参考图未修改。图集边界实际并非等高网格，拆分工具使用审查后的实际分带，避免切掉按钮或把相邻行混入。PNG透明度以实际alpha通道检查，不能从查看器对透明RGB的显示推断是否有背景。

物件图位于 `layers/products/items/`：36张按同一水彩风格新绘制，15张从已有物件图集中单独拆出，总共51张，与现有商品ID一一对应。只替换生活馆的展示图；桌面物理遮罩、空碗水位和动作资源保留。

## 页面与系统小窗

`niangao/component_skin.py` 统一PNG读取、边角保形延展与控件底面样式。主题映射：总览home、照料care、小铺/背包backpack、专注album海岸派生、聊天chat、日记diary、设置settings、相册album、状态status。

页面组合顺序为纸纹底面 → 外框 → 纸卡/页眉 → 独立贴画 → 真实内容和输入 → 焦点反馈。装饰不拦截点击。页面不把整幅参考图当默认交互层；旧整图兼容工具折叠在设置中。

工作台用chat纸面和控件，专注小窗用海岸派生纸面，气泡用聊天卡片；相册详情继承相册控件样式。操作系统原生文件选择框保持其系统行为，不伪装成应用内部页面。

## 排版与窗口修正

- 字体来源和角色仍在根目录 `fonts/roles.json`：正文14px、中文标题24px、英文手写副标题24px；辅助文案至少12px。全部动态文案由Qt绘制，可直接改文字与配置，不嵌入PNG。
- 标题按实际文本列宽计算换行高度，避免“换成两行但仍只分配一行高度”。
- 通用按钮样式不再覆盖自绘照料卡的最小高度。控件PNG边饰与中部纸纹分别延展，防止花朵或星形被拉到文字背后。
- 侧栏156px，九个真实入口保留；工作台输入和发送独立固定，模型信息/记录/额度可滚动。
- 主界面聊天输入只占右侧内容列，不再压缩左侧九个入口；小窗口中仍检查最后一个导航入口可见。
- 专注时长选择与开始/暂停/继续分行；待办自动换行并有完整文本提示。
- 所有入口统一恢复隐藏、最小化和屏幕外窗口；工作台搜索及设置入口直接进入真实功能页。
- 图像按钮按底面中心颜色选择纯白或纯黑标签，提高对比度；这是仅用于图像控件文字的可读性派生色。键盘焦点使用明确蓝色轮廓与实底。
