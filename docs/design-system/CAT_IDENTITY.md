# 年糕身份与素材使用规则

版本：1.0 · 2026-10-29。真实照片优先于 AI 概念图、UI 示例和已有生成资产。颜色允许受纸面水彩风格影响，但身份结构不能改变。

## 1. 不可丢失的辨识特征

| 特征 | 可执行检查 |
| --- | --- |
| 蓝眼睛 | 睁眼姿态保留蓝色虹膜、自然瞳孔，不改成绿色/琥珀色或夸张娃娃眼；闭眼姿态不硬画蓝眼 |
| 深棕面罩 | 保留真实面罩范围与左右非对称关系，不改成通体白猫、灰虎斑、对称 V 字模板 |
| 深色耳朵 | 耳廓比例自然，深色毛不因高光变成整块浅耳；不能用通用尖耳头像替代 |
| 不对称白额鼻纹 | 额头至鼻梁的白纹形状/偏向按照片对齐，不能改成规则对称三角或随朝向漂移 |
| 粉鼻与鼻侧深色斑点 | 斑点位于真实鼻侧邻近位置；不能移成悬空的脸颊痣、嘴边点或删除。侧别以未镜像原照核对，不能凭“猫左/看者右”口述猜测 |
| 蓬松圆脸与颈部 | 面颊长毛形成圆脸，仍有真实下颌、颈部与胸毛衔接；禁止头直接粘在躯干上 |
| 大片白胸腹、白爪 | 动作遮挡合理，白色区域不能随帧随机换色；四肢数量、关节与爪子接触正确 |
| 长而蓬松的尾巴 | 自然长度与根部连接，不改成短尾/细绳尾；主体插画尽量完整，小头像裁切另论 |
| 真实长毛毛流 | 脸颊向外下方、胸毛向下、腿毛贴结构、尾毛随尾向铺开；不是均匀塑料绒球或随机噪点 |

关键脸部特征在 48px 头像与 100% 大图均核对。小图无法可靠表现时优先使用已确认脸部近照/头像资源，不凭几笔通用猫脸宣称身份一致。

## 3. 素材等级与当前清单

| 等级 | 含义 | 使用规则 |
| --- | --- | --- |
| photo-reference | 用户真实照片，已知来源 | 可作身份依据；作为产品素材仍需确认该文件用途及透明边/裁切质量 |
| approved-niangao | 有明确确认记录的年糕专属照片/手绘资产 | 在确认范围内使用；不能把一个正面确认推广成所有生成姿态均确认 |
| candidate | AI 生成、重绘或身份尚未核实 | 不作为最终已确认形象；需标记候选/待确认，不擅自推广到新页面 |
| placeholder | 身份图缺失或待制作 | 中性纸框 +“年糕插画待制作/待确认”，占位比例与最终图一致，不放其他猫 |
| ornament | 不含角色的花边、纸纹、植物 | 可按主题使用，不能据此认定同批猫图通过身份确认 |

## 4. 姿态与画风

- 可按页选择坐姿、趴卧、侧脸、伸懒腰、打滚、睡觉，前提是有同一只年糕的合格资源。不能为凑满八页而临时换猫。
- 水墨使用自然排线与留白，淡水彩表现奶油白、深棕和蓝眼；不以粗黑线条 + 通用布偶猫模板替代真实花纹。
- 不镜像面部来生成朝向，否则鼻侧斑点和额纹会反转。需要另一侧时使用对应侧别素材；背对或遮挡时不凭空补出可见斑点。
- 肢体数量、脚掌朝向、尾根、接触面必须合理。UI 插画不得把爪子和桌面/书本融合；动作资源不以整张图平移冒充新的关节动作。
- 统一尺度以头部/肩宽的视觉标尺核对，不将所有姿态强行拉到同一个外接矩形。保留颈部与身体比例；禁止拉伸图像。
- 大幅角色图保留主体安全边 4–8%；头像可裁脸颊外侧，但眼睛、白纹、鼻点、口鼻结构完整。裁切不能连带露出图集隔壁的猫或多余毛块。
- 大图和头像都必须说明来源；照片不能标成手绘，生成图不能标成真实照片、真实录像或最终 3D 模型。

## 5. 缺素材与验收流程

先检索已确认资源及来源 → 对照真实照片检查全部特征 → 核对所需姿态/侧别/尺寸 → 使用或登记缺口。缺口先放中性可替换框，允许继续完成布局、表单与装饰，不因等素材停掉无关工作。

制作新角色图需记录：资产 ID、文件路径、真实参考来源、姿态/视角、生成/编辑方式、尺寸/Alpha、安全边、身份核对结果、确认状态、确认依据与日期、允许页面。没有确认记录不得填 `approved-niangao`。用户明确确认后再更新状态；不要反复请求已经覆盖该素材用途的确认。

建议记录模板（只记录素材，不记录密钥或私人聊天全文）：

```text
asset_id:
path:
reference_source:
pose_and_view:
origin: photo / dedicated_hand_drawn / ai_candidate / placeholder / ornament
dimensions_and_alpha:
identity_checks: eyes / mask / ears / blaze / nose_patch / neck / fur / paws / tail
review_status: candidate / placeholder / approved-niangao / ornament
confirmation_evidence_and_date:
allowed_uses:
remaining_issues:
```

进入发布资源前，在原尺寸、目标 UI 尺寸、浅色与深色底分别检查毛边、透明残留、鼻纹侧别、邻帧污染及比例。多帧动作逐帧核对，不能以一帧通过代表所有帧。自动测尺寸/Alpha 不替代身份核对；未完成项明确记录“待制作/待确认”。
