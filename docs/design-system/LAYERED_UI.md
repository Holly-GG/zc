## 组件与行为

- 正文 14px，辅助文字与标记至少 12px（历史绘制组件仍单独检查）；页面间距采用 8/12/16/24/32 体系。
- 页眉文字用布局自动换行，独立装饰仅放在预留底角，不跨过文字。聊天、专注和设置不使用该装饰。
- 照料卡片最多三列；用品区由固定三列表格改为按内容宽度重排的网格。低宽度时优先让插画退让，不缩小正文。
- 页内链接调用原导航：小铺至背包、背包至小铺、聊天至设置、日记至相册等。顶部随机待机、专注小窗、整理桌面保留。
- 聊天输入和发送固定在内容滚动区下方；会话、消息、额度、日期历史仍可滚动访问。
- 网格换列后重新保留全部行的最小高度，防止状态卡在相邻行重叠；几何检查仅检查已显示、已布局的页签。
- “参考原图”保留旧整页原图预览；“完整功能”返回独立布局。原图 ZIP 导入继续可用。
- 构建脚本保留独立 PNG 图层并嵌入字体，不再移除默认界面需要的场景、物件和装饰。
