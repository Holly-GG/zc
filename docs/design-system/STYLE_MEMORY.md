默认可见面积：纸面 65–75%，绿系 15–22%，蓝系 5–12%，古金 2–5%。按 [页面主题](PAGE_THEMES.md) 的明确比例覆盖；比例指目标视觉面积，不是 opacity 或功能数据。

正文与按钮文字对背景目标对比度至少 4.5:1，大字至少 3:1，交互边界/焦点目标 3:1。不能用低透明度淡化错误或靠颜色单独表示状态；派生色记录用途，不随意扩展彩虹色板。

## 3. 字体与排版

字体包以根目录 `fonts/` 为维护入口，`Niangao-Fonts.zip` 可单独保存。正文为 Niangao UI Sans（Noto Sans SC 400 子集），中文标题为 Niangao Journal Serif（Noto Serif SC 600 子集），英文手写副标题为 Niangao Journal Script（Allura 子集）。OFL 许可证与来源位于同目录，角色/字号配置在 roles.json。源码读取根目录包，构建复制入 EXE；EXE 旁的 fonts/ 可用于替换，缺失时使用内置包。`niangao/typography.py` 负责加载及配置边界校验，无需系统安装字体。

正文、输入及功能按钮不使用手写体；标题使用衬线，正文统一无衬线。新增文字要核对字体子集，用户输入的罕用字沿用 Qt 字体回退。不要仅更改 TTF 文件名而不更新内部字体家族名与配置；不增加未经许可的字体。

| 层级 | 逻辑 px | 字重/行高 | 规则 |
| --- | --- | --- | --- |
| 品牌 | 17–20 | 600，1.25 | 真文字，不能做成图中的假品牌按钮 |
| 页标题 H1 | 22–28 | 600–700，1.3 | 常规窗口用 22–24；大画面才放大 |
| 分区 H2 | 16–18 | 600，1.35 | 不与 H1 争夺视觉中心 |
| 正文/输入/按钮 | 13–15 | 400/600，1.45–1.65 | 字体不随窗口无限缩小 |
| 中文次要说明 | 12 | 400，1.4 | 不用 10px 中文承担操作说明 |
| 日期/短英文眉题 | 10–12 | 400–600，1.3 | 不承载必需信息，字距 0.5–1px |
| 专注时钟 | 32–40 | 500，1.15 | 计时来自真实状态，不烘焙进背景 |

英文手写副标题只作辅助，长度控制在一行、最高 22px；缺少有许可的手写字体时用现有字体或已验证的衬线后备，不下载未知字体，不把功能文本转成图片。中文标题、正文和控件字体保持统一。

## 4. 可执行尺寸与适配

全部尺寸是 Qt 逻辑像素，不是参考图原始像素，不手工再次乘 DPI。

- 保持当前默认 860×650、最小 740×540 的窗口策略；屏幕可用区更小时遵守既有降级规则，不锁死参考图尺寸。
- 外边距左右 14、顶部 12、底部 10；布局间隔 12；章节正文边距 20–24（现值横向 23）、顶部 16–20。基础间距表：4、8、12、16、24、32。
- 顶栏 60–76 高；左栏 136–156 宽（现值 142），在常规窗口约占 16–19%；不硬套参考图的大画布宽度比例。
- 页面内两栏比例均按“去除顶栏和侧栏后的可用内容”计算。内容宽度不足 600 时优先改为单列或纵向滚动，保留阅读和操作顺序，不出现横向滚动。
- 卡片间隔 8–12，内距 12–16；纸卡圆角 6–10，输入/按钮 5–8，胶囊标签 12–16。边框 1–1.2，焦点 2，选中标记 3。
- 商品卡最小宽度 144–156；常规三列，不足则两列/一列。不要在 650px 内容区强塞参考图中的六列。
- 图片保持原始比例、预留透明边；边框装饰采用保持角比例的切片绘制，不拉长花朵，不压扁年糕。没有素材时见 [身份规则](CAT_IDENTITY.md)。

## 5. 纸张、装饰与图层

粗纹水彩纸以纸纤维、浅色晕染为主：正文区域纹理叠加目标 opacity 0.08–0.18，插画边缘可到 0.25；不靠深褐污渍制造“复古”。聊天正文/输入直接使用干净纸色。

图层顺序：底色 → 低对比纸纹 → 章节插画/外框 → 有实底的信息卡 → 真文字与控件 → 焦点/错误提示。装饰不能盖在文本和控件上。独立装饰 widget 必须不抢焦点、允许鼠标穿过；优先在背景 paintEvent 绘制。

- 蓝花、白百合、铃兰、藤蔓为主；蕨叶/蘑菇只在森林主题增强，星月/星盘主要用于首页与状态主题。
- 常规外框叶片带宽 12–20，角花 40–64；离文字/按钮至少 12，输入区至少 16。短边不足时缩小角花或减少装饰，禁止角花相互挤压重叠成团。
- 撕边仅作用于纸卡外沿 1–3px；胶带宽 32–56、高 8–14；火漆章直径 20–32；每张卡至多一组胶带/章/回形针。
- 纸影只用小范围暖灰，偏移 0–2、模糊 4–8、透明度 6–10%；不要让大阴影或玻璃模糊破坏纸感。
- 功能图标统一线宽 1.5–2、常用尺寸 18–22；物品实物图独立绘制，不能以图标冒充写实/专属角色素材。
- 主信息附近不同时堆叠星光、花朵、胶带和手写字。聊天中央装饰预算为 0。
