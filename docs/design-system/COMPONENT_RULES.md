# 组件与交互状态规范

版本：1.0 · 2026-10-29。颜色、字体与尺度引用 [STYLE_MEMORY](STYLE_MEMORY.md)，页面差异引用 [PAGE_THEMES](PAGE_THEMES.md)。以下是可复用的设计合同，未接入的状态不能标记为已实现。

## 1. 共用 token 与状态

正常纸底 `#FCFAF0`，正文 `#2A472F`，强调 `#3C582C`，hover 底 `#E8E9C0`，selected 底 `#DCE3C5`，禁用底 `#ECECE2` / 文字 `#6D7467`，焦点环目标 `#3E7197`，错误 `#8D4136`。禁用文字只作说明，关键原因不能仅用极浅灰。

| 状态 | 可见反馈 | 行为约束 |
| --- | --- | --- |
| 正常 | 实底、1–1.2px 细边、清晰文案 | 命中区域与真实控件一致 |
| 悬停 | 浅绿底/深一档边线，不移动布局 | 不播放遮挡文字的大动画 |
| 按下 | 背景加深或内侧 1px 阴影 | 不改变控件宽高，避免点击错位 |
| 选中 | 持续浅绿/浅蓝底 + 图标/3px 标记 | 不能仅靠颜色；保持原选中语义 |
| 键盘焦点 | 2px 深蓝轮廓、外留 2px 安全区 | 支持现有 Tab 顺序；不能为装饰抢焦点 |
| 禁用 | 灰绿底、无 hover 强调、显示原因 | 真正禁用，不能只变灰仍触发；保留必要说明 |
| 空 | 一行原因 + 已有且可执行的下一步 | 不用伪造列表、示例历史或假成功填空 |
| 加载 | 短文案/小型指示，区域保留原尺寸 | 不假进度、不删除已有内容、不重复付费发送 |
| 错误 | 图标 + 文字 + 必要细边，说明恢复办法 | 保留用户输入、数据与原有重试规则，隐藏密钥 |

选中与禁用等状态可以组合，禁用优先取消动作与悬停，焦点/错误不能被选中底吞掉。现有 `ClickSelectComboBox` 的“仅鼠标选择、不随滚轮/方向键误改”规则保留，不为统一键盘样式破坏其特定行为；其他可编辑控件沿用自身键盘操作。

## 2. 导航与顶栏

- 侧栏宽 142 为现有基准，允许视觉适配范围 136–156；头像 48–64，外留 8。单项高 36–44、图标 18–22、图文距 8、左右内距 10–12。
- 导航图标统一墨绿线性或同族实心，不能一半 emoji、一半粗剪影。装饰不得落在导航文字、选中标记或点击区内。
- 选中项：浅绿底、3px 左标记或现有等价指示、圆角 6–8；保留完整名称。空导航不应发生，加载不更改顺序；错误只显示状态说明，不移走页面入口。
- 顶栏高 60–76，品牌和真实时间在左，三个既有快捷按钮在右；间距 8。窗口窄时压缩装饰和副标题，不藏掉快捷操作。
- 不把图中导航名称直接替换现有名称，不新增相册等假入口；参见页面映射。

## 3. 纸卡、商品卡与档案卡

- 通用内距 12–16、卡间距 12、圆角 6–10、细金/灰绿边 1–1.2；标题与内容距 8。hover/选中不改变边框外尺寸，可预留边框空间。
- 商品图区域 76–112 高、保持比例；文字不得压在图上。横卡图/文约 42:58。数量、可摆数量、价格、按钮必须是独立数据/控件。
- 大卡标题 H2，正文 13–15；装饰只在外沿，单卡最多一组胶带/回形针/章，不同时叠三种。
- 可操作卡才有 hover/按下反馈；纯档案卡不画暗示可点击的手形光标。选中显示标记；禁用说明“库存不足/资源未适配”等真实原因。
- 空网格保留筛选控件并给真实空提示；加载可使用 1–3 个无假内容的轮廓占位；错误保留原条目及可用操作。缺图用带“待制作”的位置，不把其他猫当商品/角色示例。
- 背包拖拽区域、取消和放置行为复用现有代码。装饰不成为拖拽源；拖动预览不遮住鼠标热点。库存不能先扣后用动画假装成功。

## 4. 按钮、开关与分类

- 常规按钮高 34–40，主操作 40–44，图标按钮命中至少 32×32；内距横向 12–16、纵向 7–9，圆角 5–8，图文距 6–8。
- 主按钮森林绿配高对比浅字；次按钮纸底绿字；危险按钮采用错误色文字/边线，不把删除画成普通保存按钮。hover 浅色变化后重新验证文字对比度。
- 加载保持按钮宽度，文案“保存中/连接中”等来自真实任务，防止重复提交；结束后的成功/错误反馈由真实结果驱动。
- 有现成开关时目标轨道约 40×22、命中区域至少 40×32；开/关同时用位置与文字表达，禁用附原因。不能为参考图开关改变原配置含义。
- 分类页签高 32–38，至少 8px 间距，选中底色与指示保留；空结果不禁用切回“全部”。没有对应筛选逻辑时不新增看似可用的分类。

按钮背景 / 文字配对如下；主按钮的浅字不能原样套到浅色 hover 背景：

| 类型 | 正常 | 悬停 | 按下 | 禁用 |
| --- | --- | --- | --- | --- |
| 主操作 | `#3C582C / #FCFAF0` | `#2A472F / #FCFAF0` | `#263E2A / #FCFAF0` | `#ECECE2 / #6D7467` |
| 次操作 | `#FCFAF0 / #2A472F` | `#E8E9C0 / #2A472F` | `#DCE3C5 / #2A472F` | `#ECECE2 / #6D7467` |
| 危险操作 | `#FCFAF0 / #8D4136` | `#F5EAE4 / #8D4136` | `#8D4136 / #FCFAF0` | `#ECECE2 / #6D7467` |

切换型按钮沿用“选中底 + 可读图标/文字”而非改变数据；普通保存/发送按钮不伪装持续选中态。所有类型均叠加统一焦点环；失败与加载的文字/图标规则沿用共用状态矩阵。

## 5. 输入框与表单

- 单行高 34–40，内距横向 10、纵向 7，圆角 5–8；多行正文行高 1.5–1.65、内距 10–12。输入内容 13–15，placeholder 不替代永久标签。
- 标签列宽占表单 26–30%，字段说明独立换行，行距 12、分区距 16–24。空间不足转上下标签，不挤压输入成窄条。
- focus 使用深蓝 2px，错误用错误边线 + 紧邻说明；禁用与只读可区分，只读内容仍能按原行为选择/复制。长度计数遵循实际字段上限。
- 空字段显示提示而非替用户编写真实习惯；加载/校验保留文本；错误不清空输入。密码/Key 必须遮掩，不入日志、截图或设计示例。
- 保留原输入快捷键、选择控件防误滚动设置、API 存取方式。新图中的“性格下拉”不构成把自由输入改为固定选项的授权。

## 6. 聊天组件

- 气泡宽度≤消息区 76%，内距 10–14、圆角 10–14，消息间距 12–16；本人浅蓝、年糕浅奶油绿，均用深字。长 URL/长文可换行，原文可选中复制。
- 头像 32–40，与气泡距 8；年份日期以真实记录为准；本地/API、失败/摘要来源明确，不虚构在线或已读回执。
- 会话列表、创建新轮、按日期历史、导出、实时估算/实际 token 与每日额度均保留。正文留白不意味着删掉这些入口。
- 初始态：无历史；加载态：真实请求中的提示；错误态：保留问题和重试入口；禁用态：防重复发送；新轮/摘要只改变展示承接，不删除原始历史。
- 输入区高 48–64，发送按钮宽 72–96；有真实功能才显示附件/表情按钮。token 不足与 API 错误用可读文案，不能只闪烁颜色。

## 7. 弹窗、提示与状态栏

- 常规对话框宽 360–520，不大于可用屏幕宽减 32；外距 16–24、内容间距 12–16、圆角 8–12。小屏使用滚动内容区，按钮仍可达。
- 沿用现有模态/非模态、关闭、Esc、焦点返回和确认语义，不能为统一样式改变交互行为。未实现操作不能靠“确认”弹窗伪装存在。
- 单个弹窗最多一个角花，正文/错误/密钥区不装饰。加载保持标题与取消/关闭规则；空内容说明原因，错误说明可用恢复方式；危险操作仅按已有/新授权流程执行。
- 底部状态栏最小高 24，长反馈允许两行或展开，字号 12，带状态图标/文字；无消息时显示中性提示。真实成功用绿、提示用深蓝、错误用暗红，均不能只靠颜色。
- 进度条高 12–16，加名称和实际数值；无数据为“—”，不是 0%。环形仪表直径 88–112、轨道 6–8，同样显示文字；只映射已有指标，不新增亲密度等未实现数据。
- 日历：选中浅蓝底 + 轮廓，不取消周末、农历与日期信息；无日记只是空状态。时间范围和日期来源遵守现有业务代码。

## 8. 自动补全与验收记录

缺少某状态设计时，先在现有 `theme.py` / `journal.py` / `life/window.py` / `chat_widgets.py` / `ui_controls.py` 寻找同类；使用本规范补全，记录复用组件、状态文案、颜色、尺寸与真实行为。不新增无处理函数的按钮，不以演示数据替代持久数据。

验收至少包含鼠标命中、Tab/焦点、可选中文长文、禁用无副作用、空筛选恢复、真实加载/错误反馈、740×540 与 860×650、滚动至末端及装饰安全区。修改桌面物品/工作台相关展示时运行对应真实输入检查，不把截图检查说成已验证 OS 点击穿透。
