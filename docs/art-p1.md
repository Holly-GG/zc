# P1 资源与动画需求

用户本次提供两张真实年糕照片（正面坐姿、侧面）。它们是外观首要依据，高于 AI 概念图。聊天图片当前没有可读取的本地原文件，仓库未伪造照片资产；后续将授权的原图放入 assets/references/，记录来源、使用许可和拍摄角度。

当前模型明确为 PLACEHOLDER：简单球体与锥体，不能宣称准确还原、真实长毛或最终年糕。棕白配色、蓝眼和粉鼻仅是布局示意。

正式模型验收：蓝色眼睛、深棕面罩、深耳、不对称额头到鼻梁白纹、粉色鼻头、鼻侧明显深斑、蓬松圆脸、保留颈部结构、胸腹大片白毛、白爪、长蓬松尾巴、符合真实长毛方向的毛流。照片中不可见区域需要补充背面、双侧、站立、尾部、鼻斑和额纹细节，不能自行声称还原。

资源清单：

- Blender 源文件、UV、PBR BaseColor/Normal/Roughness/AO、透明毛片与 Alpha 处理策略、低中高 LOD；优先建立无毛基础网格与骨骼。
- 身体/头颈/耳/尾/四肢骨架，眼球、眼睑、下颌控制；导出 GLB 与统一动作命名。
- idle 呼吸/眨眼/耳尾微动；name_response 转头回应；head_pet 低头蹭手；play_bow 伸展邀请；wand_chase 追逗猫棒；box_rest 进箱休息。明确循环、过渡、根运动、触地与中断规则。
- 独立动画资源或 AnimationLibrary 映射、接触/音效事件点、状态过渡测试；不把缺失动作标成 implemented。
- 逗猫棒、纸箱、零食/碗等道具；互动音频与授权；真实家园、门口迎接与跟随属于后续阶段。
- 长毛 Alpha 内部洞/断开区域的原生命中区域方案、GPU readback 性能预算和 100/150/200% DPI 回归。
