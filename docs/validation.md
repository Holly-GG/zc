## 可重复命令

```sh
bash tools/run-tests.sh
godot --path . --audio-driver Dummy -- --render-smoke
# 有 X11、合成器、xdotool 时：
python3 tools/test-desktop-x11.py
```

Windows：`tools/bootstrap-windows.ps1` → `tools/run-tests.ps1` → `tools/export-windows.ps1` → `tools/acceptance-windows.ps1 -ResetPosition`。脚本直接保留 Godot 退出码；原生验收抛异常即失败，不得把部分 PASS 当成全部通过。

## 故障与当前限制

Wine 初始化遇到其隔离系统目录缺少 zlib，修复测试环境后 exe 渲染成功。穿透失败原因尚未在原生 Windows 上定位，可能涉及 Wine/X11 区域与输入路由兼容性，**不能确认为仅 Wine 的问题**。核对 Godot 4.6.3 官方 Windows 实现：使用 CreatePolygonRgn + SetWindowRgn，当前方案确实设置输入/裁剪区域，并非只设置透明参数。

原生 Windows 若同样失败，需要继续检查 OS 区域和实际点路由，再采用独立 GDExtension 的多区域 HRGN/原生窗口命中方案；当前尚未实现该扩展，不能宣称已解决。

Alpha 轮廓只支持单连通外边界，不能处理透明内洞/多片断开的正式长毛资产；约 10Hz 更新与0.5像素简化存在边缘误差。初次 GPU 图像未就绪时最多2秒保留完整窗口输入；不会把未就绪说成穿透有效。未来更换模型需重新验收。

无真实家园、门口迎接动画、跟随移动、语音识别、最终年糕模型、真实毛发、五个非 idle 动画、音效、安装器和签名。工作/睡眠模式仅保存配置并派发事件。照片是 P1 依据，当前 PLACEHOLDER 不代表准确还原。
